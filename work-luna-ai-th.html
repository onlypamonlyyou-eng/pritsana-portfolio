ใช้ AI ช่วย ตรวจด้วยมนุษย์

เขียนความต้องการให้ชัด ตรวจทุกแผนก่อนแตะข้อมูลผู้ป่วยจริง และยืนยันผลทดสอบก่อนปล่อยใช้งาน

  • พัฒนาด้วยความช่วยเหลือของ Claude Code
  • ทดสอบกับ Claude API จริง
  • สำรองฐานข้อมูลก่อนเปลี่ยนโครงสร้างทุกครั้ง
  • รับฟีดแบ็กจากพนักงานคลินิกและผู้บริหาร
ธรรมาภิบาล

5 จาก 10 คำถามที่เขียนไว้ก่อนเสนอผู้บริหาร

ข้อมูลอะไรที่ AI ใช้ได้ และใช้ไม่ได้?

ใช้ได้เฉพาะโพสต์ของคลินิกที่อนุมัติแล้วและไฟล์ FAQ ที่ตรวจแล้ว ห้ามใช้ความรู้การแพทย์ทั่วไปมาวินิจฉัยเฉพาะบุคคล หรืออ้างราคาที่ไม่อยู่ในฐานความรู้

ถ้าไม่รู้คำตอบจะทำอย่างไร?

ใช้สคริปต์ fallback ที่กำหนดไว้ ส่งต่อให้ทีมแอดมินทันที ห้ามเดา

ส่งต่อมนุษย์เมื่อไหร่?

เมื่อมี Red Flag คำถามเรื่องอาการหรือการเงิน ผู้ป่วยขอคุยกับคน หรือเมื่อ AI หาคำตอบไม่เจอ

ทำไมไม่ใช้เกณฑ์ Confidence Score?

Claude API ไม่มีตัวเลขความมั่นใจจริง กฎแบบต่ำกว่า 85% จึงสร้างไม่ได้ ระบบจึงยึดกับฐานความรู้ที่อนุมัติแล้ว

ใครตรวจคำตอบ และบ่อยแค่ไหน?

สุ่มตรวจ 5 ถึง 10% ของบทสนทนาทุกสัปดาห์ โดยพยาบาลหรือแอดมินอาวุโส
